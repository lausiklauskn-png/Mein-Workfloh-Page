# Fotos für die Werbetechnik-Vorlage

Die Vorlage wird **ohne Bilder** ausgeliefert. Eigene Fotos können hier abgelegt
oder direkt in der laufenden App **per Drag & Drop** auf die jeweilige Bildfläche
gezogen werden (das 📷-Symbol oben rechts an jeder Fläche öffnet zusätzlich einen
Datei-Dialog). Per Drag & Drop eingesetzte Bilder werden lokal im Browser
gespeichert (kein Datei-Upload nötig).

Empfohlenes Seitenverhältnis: Hero & Karten 16:10, Detailbilder 4:3,
Team-/Porträtbilder 3:4.

## Bildflächen in der App
- Startseite/Hero
- Leistungs-Karten (Folierung, Beschriftung, Digitaldruck, Schilder,
  Lichtwerbung, Leuchtbuchstaben, Gravur, Fensterfolie)
- Referenzen-Galerie
- Team-Karten

Solange keine Bilder gesetzt sind, zeigen die Flächen neutrale CSS-Platzhalter
bzw. eigene Leucht-Art.
